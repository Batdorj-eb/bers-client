# Монгол Мэдээ — Next.js жишиг мэдээний сайт

Энэ бол **Next.js 16 (App Router)** болон **Tailwind CSS**-ээр хийсэн энгийн, эхлэн суралцагчдад зориулсан мэдээний сайтын жишиг төсөл.

## Ашигласан технологи

- **Next.js 16** — App Router (файлын систем дээр суурилсан чиглүүлэлт)
- **React 19**
- **Tailwind CSS 4** — CSS-ийн класс ашиглан загварчлах
- Өгөгдлийг `lib/newsData.js` файлд энгийн JavaScript массив хэлбэрээр хадгалсан (database шаардлагагүй)

## Фолдерын бүтэц

```
news-site/
├── app/
│   ├── layout.js          # Бүх хуудсыг ороосон үндсэн layout (Header + Footer)
│   ├── page.js             # Нүүр хуудас (/) — мэдээний жагсаалт
│   ├── globals.css         # Ерөнхий CSS
│   ├── not-found.js        # 404 хуудас
│   └── news/[slug]/
│       └── page.js         # Нэг мэдээний дэлгэрэнгүй хуудас (/news/mongolian-economy-grows г.м)
├── components/
│   ├── Header.js            # Толгой хэсэг
│   ├── Footer.js            # Доод хэсэг
│   └── NewsCard.js          # Мэдээний карт (жагсаалтад ашиглагдана)
└── lib/
    └── newsData.js           # Жишиг мэдээний өгөгдөл + туслах функцууд
```

## Хэрхэн ажиллуулах вэ

```bash
npm install
npm run dev
```

Дараа нь браузераар `http://localhost:3000` хаягаар орж үзнэ.

## Шинэ мэдээ хэрхэн нэмэх вэ

`lib/newsData.js` файл дотор `newsList` массивт шинэ объект нэмэхэд л шинэ мэдээ автоматаар нүүр хуудас болон дэлгэрэнгүй хуудсанд гарч ирнэ. `slug` талбар нь URL-д ашиглагддаг тул давхардахгүй, латин үсгээр бичих ёстой.

## Дараагийн алхмууд (жинхэнэ төсөлд)

- `lib/newsData.js`-ийг жинхэнэ backend API эсвэл өгөгдлийн сан (MySQL, PostgreSQL) руу солих
- Хайлт, ангилалаар шүүх функц нэмэх
- Админ панель нэмж мэдээ удирдах
- Зургийг `next/image`-ээр солиод `next.config.js`-д `images.remotePatterns` тохируулах
